# App Store Yayın Kontrol Listesi

## Metadata

- [ ] Nihai uygulama adı: `Okçuların Son Kalesi`
- [ ] Alt başlık (30 karakter sınırını doğrula): `[DOLDUR]`
- [ ] Türkçe ve İngilizce açıklamalar gözden geçirildi
- [ ] Anahtar kelimeler: `[DOLDUR]`
- [ ] Destek URL’si: `[DOLDUR]`
- [ ] Yayındaki gizlilik URL’si: `[DOLDUR]`
- [ ] Pazarlama URL’si (isteğe bağlı): `[DOLDUR]`
- [ ] Birincil/ikincil kategori: `[DOLDUR]`
- [ ] Yaş derecelendirmesi anketi tamamlandı
- [ ] Telif hakkı sahibi ve yılı: `[DOLDUR]`

## Görseller ve build

- [ ] 1024×1024 RGB uygulama ikonu doğrulandı
- [ ] Güncel App Store Connect gereksinimlerine göre iPhone ekran görüntüleri yüklendi
- [ ] iPad destekleniyorsa gerekli iPad ekran görüntüleri yüklendi
- [ ] Ekran görüntüleri gerçek mevcut oynanışı gösteriyor
- [ ] Splash ve ikon gerçek cihazda kontrol edildi
- [ ] Bundle ID, Team ID, Version ve Build doğru
- [ ] Release archive gerçek cihaz build’inden üretildi

## Review ve uygunluk

- [ ] Test hesabı gerekmiyor; bu durum review notlarında belirtildi
- [ ] Review notlarında çevrimdışı oyun ve yerel kayıt açıklandı
- [ ] Veri toplama beyanı son binary ile karşılaştırıldı
- [ ] App Privacy yanıtları güncel gizlilik taslağıyla eşleşiyor
- [ ] Export compliance soruları kullanılan şifreleme davranışına göre doğru yanıtlandı
- [ ] İçerik hakları: tüm kod/görseller özgün veya kullanma hakkı doğrulanmış
- [ ] Reklam, analitik, takip, hesap ve satın alma olmadığı doğrulandı
- [ ] Crash, bozuk bağlantı ve placeholder metin kalmadı
- [ ] Internal ve gerekiyorsa External TestFlight testi tamamlandı

App Store Connect’in alanları ve ekran görüntüsü boyutları zamanla değişebilir;
yükleme gününde Apple’ın güncel gereksinimleri yeniden kontrol edilmelidir.
